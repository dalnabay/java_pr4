## Работа 4. Перечисления

### Времена года

`Season` задает четыре допустимых сезона. У каждой константы есть средняя температура, переданная конструктору. `getDescription()` возвращает описание, причем для `SUMMER` метод переопределен и сообщает о теплом времени года. Для остальных сезонов возвращается описание холодного времени года по условию задания.

В `TestSeason` выбирается любимый сезон. Метод `love()` использует `switch` для вывода сообщения. Затем через `values()` перебираются все сезоны с их температурой и описанием. Температуры используются как пример данных.

### Ателье

`Size` содержит размеры `XXS`, `XS`, `S`, `M`, `L` и европейские значения `32`, `34`, `36`, `38`, `40`. Для `XXS` возвращается описание детского размера, для остальных возвращается описание взрослого.

Общий абстрактный класс `Clothes` хранит размер, цену и цвет. Конкретные объекты одежды создаются через наследников:

| Объект | Класс | Доступные интерфейсы |
| --- | --- | --- |
| Футболка | `TShirt` | `MenClothing`, `WomenClothing` |
| Штаны | `Pants` | `MenClothing`, `WomenClothing` |
| Юбка | `Skirt` | `WomenClothing` |
| Галстук | `Tie` | `MenClothing` |

`Atelier` получает массив `Clothes[]`. Методы `dressMan()` и `dressWomen()` определяют подходящие вещи по интерфейсам и выводят сведения о них. Один объект футболки или штанов подходит для обоих вариантов.

### Интернет-магазин

`Category` ограничивает набор категорий: книги, электроника и одежда. `Product` хранит название товара, цену и категорию. `Shop` объединяет массив каталога, список корзины и ввод пользователя.

Для входа используются учебные данные: логин `vsevolod`, пароль `java17`. Они проверяются методом `signIn()`. Неверный вход завершает программу.

После входа работает меню в цикле `do while`. Каталог открывается через `browseCatalog()`: сначала выбирается категория, затем товар. Подходящие товары собираются в отдельный список, а выбранный объект добавляется в корзину. Например, книга «Основы Java» стоит `750` рублей.

`printBasket()` показывает товары и итоговую сумму. `checkout()` проверяет, что корзина непустая, выводит ее содержимое и очищает после оформления. Повторное оформление без добавления товаров отклоняется. Обрабатываются неверные номера и нечисловой ввод меню. При завершении ввода программа выходит из меню.

Это консольная модель: реальной оплаты и сохранения покупок после закрытия нет.

### Компьютер

`Computer` содержит марку из `Brand` и три объекта компонентов. `Processor` хранит модель, количество ядер и частоту. `Memory` хранит объем и частоту памяти. `Monitor` хранит диагональ и разрешение.

В `TestComputer` сначала создаются компоненты, затем объект компьютера. Выводятся общее описание и отдельные характеристики. Это пример композиции, когда сложный объект собирается из более простых.

## Работа 4.1. Наследование и перегрузка

### 1. Обычные геометрические фигуры

В пакете `shapes` класс `Shape` является обычным родительским классом. От него наследуются `Circle`, `Rectangle`, `Square`. У фигур переопределены тип, описание, площадь и периметр.

В `TestShape` создаются круг радиусом `3`, прямоугольник `4 × 7` и квадрат со стороной `5`. Через общий массив вызываются методы конкретных фигур. Для квадрата обе стороны всегда меняются вместе.

### 2. Телефоны

`Phone` хранит номер, модель и вес. Предусмотрены три конструктора: без параметров, с номером и моделью, со всеми тремя значениями. Конструктор с тремя параметрами сначала вызывает конструктор с двумя через `this(...)`.

В `TestPhone` создаются три телефона. Для них вызываются `getNumber()` и два варианта `receiveCall()`: с именем звонящего и с именем вместе с номером. Метод `sendMessage(String... numbers)` принимает разное количество номеров и выводит получателей. Реальная отправка сообщений не выполняется.

### 3. Люди

`Person` содержит имя и возраст. `move()` и `talk()` выводят действия с именем человека. В `TestPerson` создаются два объекта: один получает значения по умолчанию, другой получает имя «Андреев Всеволод» и возраст из учебного примера. Каждый объект выполняет оба действия.

### 4. Матрицы

`Matrix` хранит двумерный массив и размеры. Переданные данные копируются, чтобы последующее изменение исходного массива не изменяло объект.

`add()` выполняет поэлементное сложение. `multiply(double)` умножает элементы на число. Перегруженный `multiply(Matrix)` вычисляет произведение: для каждой строки результата накапливаются вклады элементов первой матрицы и строк второй. `print()` выводит строки.

Все операции возвращают новые матрицы. При несовместимых размерах выбрасывается исключение. В `TestMatrix` используются матрицы `[[2, 1], [0, 3]]` и `[[4, 2], [1, 5]]`. Их произведение равно `[[9, 9], [3, 15]]`.

### 5. Читатели и книги

`Reader` содержит ФИО, номер билета, факультет, дату рождения и телефон. `Book` содержит название и автора.

Методы `takeBook()` и `returnBook()` имеют по три варианта: для количества книг, набора названий и набора объектов `Book`. В последнем случае из объектов извлекаются названия. Программа формирует сообщения о выдаче и возврате, но отдельный учет выданных экземпляров не ведется.

В `TestReader` создаются два читателя и три книги. Для читателей вызываются все варианты методов.

### 6. Работники и менеджеры

`Employer` хранит имя, фамилию и месячную зарплату. `Manager` наследует эти данные и добавляет среднюю месячную доплату за продажи.

`getIncome()` возвращает годовой доход. Для работника это зарплата, умноженная на `12`. У менеджера добавляется доплата, также умноженная на `12`. Такое толкование зафиксировано в реализации, поскольку конкретные данные для расчета по рабочим дням в условии не заданы.

В `TestEmployer` оба объекта находятся в массиве `Employer[]`. Несмотря на общий тип ссылок, доход менеджера вычисляется переопределенным методом.

### 7. Учащиеся

`Learner` содержит имя. `Student` и `Schoolchild` наследуются от него и обозначают разные типы учащихся. В `TestLearner` создается общий массив из двух студентов и двух школьников. Проверка `instanceof` позволяет вывести эти группы отдельно.

### 8. Абстрактные фигуры

В пакете `abstractshapes` выполнен вариант с абстрактным `Shape`. Он задает общие поля и методы, но не может создаваться напрямую. `Circle` и `Rectangle` реализуют расчет площади и периметра. `Square` наследует формулы прямоугольника и сохраняет равные стороны.

В упражнении исправлены недопустимые вызовы методов подкласса через общий тип. Для получения радиуса выполняется приведение к `Circle`, длины к `Rectangle`, стороны к `Square`. Приведение не меняет объект и допустимо только при соответствии его реального типа.

### 9. Мебель

Абстрактный класс `Furniture` задает материал, цену и метод вида мебели. Наследники `Chair`, `Table`, `Wardrobe` описывают стул, стол и шкаф.

`FurnitureShop` содержит список мебели. Он позволяет добавить предмет, показать каталог и купить предмет по индексу. Покупка удаляет объект из каталога и возвращает его. В демонстрации создаются три предмета, покупается первый и выводится оставшийся список.

### 10. Транспорт

`Transport` содержит скорость, тариф за пассажира на километр и тариф за тонну груза на километр. `Car`, `Plane`, `Train`, `Ship` задают значения для разных видов транспорта.

Время вычисляется как расстояние, деленное на скорость. Цена пассажирской перевозки равна расстоянию, умноженному на число пассажиров и тариф. Для груза вместо пассажиров используется масса в тоннах.

В `TestTransport` создаются четыре транспортных средства и рассчитываются поездки на одинаковое расстояние `1000` км для трех пассажиров и двух тонн груза. Тарифы учебные, вместимость и задержки не учитываются.

## Какие приемы используются в работе

Перечисления задают допустимые значения. Наследование объединяет родственные классы. Интерфейсы определяют доступные действия одежды. Перегрузка позволяет вызывать методы и конструкторы с разными наборами параметров. Переопределение меняет поведение наследника. Композиция используется у компьютера и магазина, которые содержат другие объекты.
